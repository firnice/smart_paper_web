# 39-practice-page-status-feedback-fix

## 背景

`PracticePage` 在提交练习结果后，之前只会提示：

- 已记录本次做对
- 已记录本次做错
- 已记录本次跳过

但页面不会重新拉取这道错题，也不会展示状态回流结果。

这会让用户看不见一个关键事实：

- 本次回填后，这道题当前到底是 `new`
- 还是变成了 `reviewing`
- 还是已经进入 `mastered`

而后端其实已经在 `create_study_record` 里自动处理了这些状态变化：

- `incorrect` → `reviewing`，并增加 `error_count`
- `correct` + `mastery_level >= 4` → `mastered`
- `correct` 且原状态为 `new` → `reviewing`

所以之前的问题不是后端没回流，而是前端没有把回流结果重新展示出来。

## 本次修复

### 1. 提交结果后刷新当前错题

`submitResult()` 在调用 `createStudyRecord()` 成功后，会重新拉取当前错题并更新页面状态。

### 2. 成功提示补充“当前状态”

提示从单纯的“已记录”改为：

- 已记录本次做对，当前状态：已掌握
- 已记录本次做错，当前状态：复习中
- 已记录本次跳过，当前状态：新错题 / 复习中 / 已掌握（取决于后端当前状态）

### 3. 页面头部直接展示当前状态

在回填页标题下补充：

- 当前状态
- 最近回填日期（如果有）

让用户在页面内就能感知这道题的回流结果，而不必手动退出再回工作台确认。

## 结果

修复后，`PracticePage` 不再只是“提交成功提示页”，而是能直接体现：

- 本次回填已记录
- 当前错题状态是什么
- 状态是否已进入复习或掌握

这让 M2 主链路里的“练习 → 状态回流”感知更完整。
