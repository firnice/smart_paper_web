# 36-student-image-surface-completion

## 背景

前几轮已经打通：
- 工作台保存错题时不丢图
- 错题本与错题详情页能显示图

但学生高频页面仍未完全跟进：
- 首页最近错题
- 练习回填页
- 打印选题页

## 本次补齐

### 首页 `/home`
- 最近错题卡片支持图片预览

### 练习页 `/practice/:id`
- 回填结果前可先看到题图，再决定做对/做错/跳过

### 打印页 `/print`
- 选题时可看到题图预览，降低只看标题误选的概率

## 结果

带图错题现在已经覆盖学生端主要浏览链路：
- 工作台
- 首页
- 错题本
- 错题详情
- 练习页
- 打印页
