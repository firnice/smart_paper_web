# 44-print-to-practice-next-step-link

## 背景

学生端打印页 `PrintPage` 已经能调用真实导出接口生成 PDF，但此前导出成功后的页面只停留在：

- 下载 / 打开 PDF
- 重新设置

这意味着主链路虽然技术上可走通，但用户在页面内感知到的流程仍然是断的：

- 选错题
- 打印
- 然后下一步该干嘛，需要自己想

## 问题

Smart Paper 当前主链路目标是：

- 选错题
- 打印重做
- 线下完成
- 回填结果

如果打印完成后没有一个明显的“下一步”，用户很容易停在导出页，不知道接下来该去哪里记录结果。

## 本次修复

当打印包生成成功后：

- 如果本次已选错题不为空
- 页面新增一个明确按钮：
  - `去回填第一道题的练习结果`

当前实现先用已选列表中的第一题作为下一步入口。

## 结果

修复后：

- 打印页不再只是“导出完成页”
- 会主动把用户往“结果回填”这一步引导
- 学生端“打印 → 回填”主链路更连续

## 说明

这还不是最终形态的“批量打印后逐题回填工作流”，但已经先把最明显的流程断点补上，适合当前里程碑收口阶段。
